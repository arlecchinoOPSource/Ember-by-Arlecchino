## Not shared yet: audio

Terminal's sounds are **not** part of this package. Their redistribution rights were recorded for Terminal only (`docs/AUDIO-ASSETS-v2.0.md` in Terminal):

- Startup, close and error sounds by Arlecchino: supplied by the owner "for redistribution in Terminal". Using them in Ember needs the owner's explicit confirmation.
- Thock keys (unicaegames, CC0) and Kenney interface clicks (CC0): reusable without conditions.
- Clicky keys (eklee/qubodup, CC BY 3.0): reusable only with the attribution shown in each app.

Audio sharing is planned with Ember issue #4 once the owner confirms the Arlecchino sounds.
